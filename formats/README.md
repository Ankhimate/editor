# Ankhimate Formats

Native `.ankh` serialization, version migration, PSD import, and importer
registry for [Ankhimate](https://github.com/Ankhimate/editor).

Foreign formats such as Spine and DragonBones are sandboxed packages in
[community-plugins](https://github.com/Ankhimate/community-plugins).
