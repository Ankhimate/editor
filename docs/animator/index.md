# Animator manual

The animator path follows the work: organize artwork, build a setup rig, create
animation clips, and export data. Keep **Setup** and **Animate** mode visible in
your mental model: Setup changes the reusable rig; Animate records poses.

Screenshots are intentionally pending until a stable, reproducible capture pass.
The text and controls are usable without them, and no mock image is presented as
the running editor.
